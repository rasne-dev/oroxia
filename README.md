# Oroxia

> AI-powered Android home screen organizer

Oroxia automatically categorizes your installed apps using Gemini AI and organizes them into folders on your home screen — silently, without spamming notifications.

## Features

- 🤖 AI-powered app categorization (Gemini 2.0 Flash)
- 📁 Auto folder creation by category (Career, Shopping, Finance, Social…)
- 🔕 No notification spam — batches new apps, notifies weekly (configurable)
- 📴 Works offline after first scan
- 🔒 Open source, no ads, no tracking

## Tech Stack

- Kotlin + Jetpack Compose
- Gemini 2.0 Flash API
- Room + DataStore
- WorkManager

## Getting Started

1. Clone the repo
2. Add your Gemini API key to `local.properties`:
   ```
   GEMINI_API_KEY=your_key_here
   ```
3. Build and run via Android Studio

# Oroxia

> Yapay zeka destekli Android ana ekran düzenleyici

Oroxia, yüklü uygulamalarınızı Gemini yapay zekası ile otomatik olarak kategorilere ayırır ve ana ekranınızda klasörlere düzenler — sessizce, bildirim spam'i yapmadan.

## Özellikler

- 🤖 Yapay zeka ile uygulama kategorileme (Gemini 2.0 Flash)
- 📁 Otomatik klasör oluşturma (Kariyer, Alışveriş, Finans, Sosyal…)
- 🔕 Bildirim spam'i yok — yeni uygulamaları toplu bildirir, haftada bir (ayarlanabilir)
- 📴 İlk taramadan sonra çevrimdışı çalışır
- 🔒 Açık kaynak, reklam yok, takip yok

## Teknoloji

- Kotlin + Jetpack Compose
- Gemini 2.0 Flash API
- Room + DataStore
- WorkManager
